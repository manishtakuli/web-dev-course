🌐 HTML — Web Development ----
This repository contains my HTML learning journey, practice files, and exercises. It covers the fundamentals of HTML and the concepts required to build the structure of modern web pages.

📚 Topics Covered
1. Introduction to HTML
Learned the fundamentals of HTML and understood how it is used to structure content on web pages.

2. Basic HTML Structure
Learned the standard structure of an HTML document, including <!DOCTYPE html>, <html>, <head>, and <body>.

3. HTML Elements and Tags
Learned about HTML elements, tags, attributes, and how they work together to create webpage content.

4. Headings and Paragraphs
Learned how to organize and display text using headings, paragraphs, and different text-related HTML elements.

5. Links
Learned how to create hyperlinks and connect different pages and resources using the <a> element.

6. Images
Learned how to add images to webpages using the <img> element and explored important image attributes.

7. Lists
Learned how to create ordered lists, unordered lists, and nested lists to organize information.

8. Tables
Learned how to create and structure tables using rows, columns, table headings, and table data.

9. Forms
Learned how to create HTML forms and use different input fields to collect information from users.

10. Semantic HTML
Learned about semantic HTML elements  to create meaningful webpage structures.

11. HTML Attributes
Learned how attributes provide additional information to HTML elements and control their behavior and properties.

12. Multimedia
Learned how to add multimedia content such as audio and video to webpages using HTML5 elements.
